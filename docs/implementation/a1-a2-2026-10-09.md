## Rendering decision and specification deviation

Prerendering was attempted. The JavaScript-disabled test could not preserve query-based type preselection on the prerendered page. A2 therefore uses the SSR fallback permitted by section 11 of `tech.md`.

The response uses `Cache-Control: private, no-store`, which differs from the public cache policy prescribed for that fallback. The page sets the visitor's fill-time cookie and can render rejected form values; sharing such responses would risk sharing visitor state. This deviation needs review before merge. `tech.md` has not been edited.
